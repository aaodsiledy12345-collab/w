상품 데이터베이스 API

실제 제품명·판매 가격·사진을 검색하는 API입니다. 1,000만 개를 HTML에 전부 저장하지 않고, 서버가 검색 결과만 페이지 단위로 돌려주는 방식입니다.

상품 API가 연결되지 않았습니다. 실제 상품·사진·가격은 아직 제공되지 않습니다.

검색 요청에 q, category, page, pageSize=24, imageRequired=true, currency=KRW를 전달합니다. 서버가 실제 상품 사진 URL을 제공하지 않는 상품은 화면에 표시하지 않습니다.

실시간 가격 API

상품 카탈로그와 별개로, 저장된 제품의 최신 가격을 주기적으로 새로 확인합니다.

연동되지 않았습니다. 실시간 가격 API 연결 전에는 가격을 표시하지 않습니다. 내장 샘플 가격은 제거되어 있습니다.
테스트는 최대 15초 기다린 뒤 결과를 표시합니다. 브라우저가 CORS 오류를 내거나 API에서 다른 형식으로 응답하면 연결에 실패합니다.

상품 API 응답 형식

서버가 공급사의 허가된 카탈로그/가격 데이터를 정리해 아래 형태로 반환해야 합니다. 사진 URL은 해당 실제 상품 사진이어야 합니다.

{
  "total": 10000000,
  "page": 1,
  "pageSize": 24,
  "currency": "KRW",
  "updatedAt": "2026-10-14T06:00:00Z",
  "items": [{
    "id": "vendor-sku-123",
    "category": "gpu",
    "brand": "ASUS",
    "name": "실제 판매 모델명",
    "priceKrw": 929000,
    "imageUrl": "https://seller.example/real-product-photo.jpg",
    "url": "https://seller.example/product/123",
    "socket": "LGA1700",
    "memory": "DDR5",
    "form": "ATX",
    "specs": {"VRAM":"12GB", "인터페이스":"PCIe"}
  }]
}

상품 검색 경로와 가격 추적 경로는 별도로 둘 수 있습니다. 총 상품 수(total)가 1,000만이어도 브라우저로는 검색된 24개씩만 가져옵니다. 전체 수는 서버의 데이터베이스가 실제로 보유할 때만 표시할 수 있습니다.

실제 연동을 위해 알아둘 점

서비스를 공개하기 전에는 이 부분을 꼭 해결해야 합니다.

1. 가격 출처와 사용 허가

쇼핑몰·가격 비교 서비스의 공식 API 또는 사용 허가된 피드를 연결해야 합니다. 웹페이지를 무단으로 반복 수집하면 약관·접근 제한 문제가 생길 수 있습니다.

2. API 키는 서버에 보관

비밀키를 HTML 파일 안에 넣으면 방문자가 볼 수 있습니다. API 키와 공급사 연동은 별도 서버에서 처리하세요.

3. 모든 회사·제품 전체 목록

백만 종을 실제로 제공하려면 공급사 카탈로그, 모델 식별자, 사진, 재고·가격 이력 데이터베이스가 필요합니다. 이 데모에 모든 제품이 들어 있는 것은 아닙니다.

4. 가격 알림의 한계

브라우저 탭이 닫혀 있으면 단일 HTML은 계속 실행할 수 없습니다. 상시 감시·푸시 알림은 서버 스케줄러와 알림 서비스가 필요합니다.

테스트용 가격 변화: 데모 모드에서 아래 버튼을 눌러 가격이 변하는 상황과 목표가 알림이 작동하는지 확인할 수 있습니다. 이것은 실제 시장 가격 변경이 아닙니다.
