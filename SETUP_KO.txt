PC 견적 도우미 — 태블릿용 온라인 API 서버 배포 안내

이 패키지는 실시간 가격을 임의로 만들지 않습니다. 실제 다나와 상품 검색/가격 조회는 ReefAPI의 다나와 API를 사용하며, API 키가 없으면 검색 API가 오류를 반환하고 가격을 꾸며서 보여주지 않습니다.

포함 파일
- pc_quote_app.html: 기존 PC 견적 화면(태블릿 브라우저용)
- pc_catalog_server.py: 온라인 상품 검색/가격 API 서버
- catalog_template.csv: 별도 허가받은 공급사 상품 CSV용 열 제목
- render.yaml: Render 배포 설정 초안

온라인 서버 배포(계정 필요)
1. Render 계정을 만들고 이 폴더를 새 GitHub 저장소에 올립니다.
2. Render에서 New + > Blueprint를 선택하고 저장소를 연결합니다. render.yaml 설정을 읽어 웹 서비스를 만듭니다.
3. 서버 환경변수 REEF_API_KEY에 ReefAPI에서 발급한 API 키를 입력합니다. 키를 HTML 파일이나 공개 저장소에 넣지 마세요.
4. 배포 후 https://내-서비스.onrender.com/health 를 열어 ok:true, liveProviderConfigured:true를 확인합니다.
5. HTML의 [가격 연동 안내] 메뉴에서 상품 API URL에 https://내-서비스.onrender.com/api/catalog/search 를 입력하고, 가격 API URL에 https://내-서비스.onrender.com/api/parts/prices 를 입력합니다.
6. HTML 파일을 태블릿에서 열어 온라인 상품 검색을 사용합니다. HTML을 웹에 올려 함께 운영할 수도 있습니다.

실제 가격 공급원
- API 문서: https://reefapi.com/danawa-api
- API 키는 공급사 계정에서 직접 발급받아야 합니다. 제공 서비스의 무료 크레딧/유료 사용량, 응답 필드, 데이터 이용 약관을 확인하세요.
- 가격 조회는 실제 API 호출이 발생할 수 있으므로 과도하게 반복하지 않도록 서버가 300초 캐시를 적용합니다. API 공급사에서 가격을 제공하지 않으면 가격은 null로 반환되고 임의의 가격으로 대체하지 않습니다.
- 검색 응답에서 실제 이미지 URL이 제공된 제품만 반환합니다. 일부 상품은 사진이 없어 검색 결과에서 제외될 수 있습니다.
- 이 연동은 국내 다나와 검색을 위한 시작점입니다. 전 세계 1,000만 상품의 완전한 카탈로그가 자동으로 포함되는 것은 아닙니다.

로컬 테스트(선택)
Windows에서 Python 3.10 이상을 설치한 뒤 이 폴더에서:
  $env:REEF_API_KEY="발급받은_키"
  py pc_catalog_server.py --db pc_catalog.sqlite3 --port 8787
브라우저에서 http://127.0.0.1:8787/health 를 확인합니다. 태블릿이 이 서버를 쓰려면 같은 네트워크에 연결된 PC의 LAN IP가 필요하고, PC를 계속 켜 두어야 합니다. 태블릿만으로 온라인 서버를 계속 운영하는 방식은 아닙니다.

보안 및 배포 주의
- API 키는 절대로 HTML/JS에 넣지 말고 서버 환경변수로만 설정합니다.
- 공개 서버는 API 키 보호, 사용량 제한, 로그, CORS 도메인 제한, 가격 데이터 라이선스 검토를 추가해야 합니다.
- 현재 서버는 상품 검색/가격 API 연결용 시작 버전이며, 계정 생성이나 실제 외부 배포를 대신 수행할 수 없습니다.
